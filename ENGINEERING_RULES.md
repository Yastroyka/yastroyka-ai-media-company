# ENGINEERING RULES
1. TypeScript/Node.js first.
2. H3 for owned HTTP services.
3. Vue 3/Nuxt 4 for owned web/admin.
4. PostgreSQL canonical.
5. Elasticsearch derived projection.
6. Redis/BullMQ for jobs.
7. Temporal for durable workflows.
8. n8n is edge integration/operator automation, not canonical state.
9. Python prohibited without ADR.
10. React/Next prohibited as default stack.
11. External AI gateway is not internal routing authority.
12. Production commerce bridge is read-only.
13. Test + evidence are part of every deliverable.
